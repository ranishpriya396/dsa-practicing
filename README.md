# 1-Hour Daily DSA Challenge 🚀

A structured repository dedicated to mastering Data Structures and Algorithms (DSA) in just 1 hour every day.

## 🎯 Current Focus Roadmaps

### Phase 1: Foundational Sorting Algorithms
- [ ] **Selection Sort**
  - Time Complexity: O(N²) | Space Complexity: O(1)
  - Key concept: Find the minimum element and swap it to the front.
- [ ] **Insertion Sort**
  - Time Complexity: O(N²) | Space Complexity: O(1)
  - Key concept: Build the sorted array one item at a time.
- [ ] **Bubble Sort**
  - Time Complexity: O(N²) | Space Complexity: O(1)
  - Key concept: Repeatedly swap adjacent elements if they are in the wrong order.

### Phase 2: Searching Techniques
- [ ] **Binary Search**
  - Time Complexity: \(O(\log N)\) | Space Complexity: O(1)
  - Key concept: Divide and conquer on a sorted array.

### Phase 3: LeetCode Array Problems
- [ ] Two Sum
- [ ] Best Time to Buy and Sell Stock
- [ ] Move Zeroes
- [ ] Remove Duplicates from Sorted Array
- [ ] Merge Sorted Array

## ⏱️ Daily 60-Minute Routine

```text
┌──────────────────────────────┬──────────────────────────────┬──────────────────────────────┐
│       10 MINS: PLAN          │        35 MINS: CODE         │        15 MINS: PUSH         │
│  Read problem & map approach │ Write clean solution alone   │ Optimize, comment, & commit  │
└──────────────────────────────┴──────────────────────────────┴──────────────────────────────┘
```

1. **Understand (10 mins):** Pick the daily problem. Work out the logic on paper before typing.
2. **Execute (35 mins):** Code the solution. If stuck for more than 25 minutes, review editorial hints.
3. **Document (15 mins):** Clean the variable names, add time/space complexity notes, and push to GitHub.
